# Folio

A quiet reading room for your PDF and EPUB books. Folio brings your library, saved reading positions, and personal reading preferences together in a simple, comfortable interface.

## Features

- Browse and search your library, with personal shelves and favorites.
- Read PDFs and EPUBs, save bookmarks, and return to your last reading position.
- Choose a reading atmosphere, adjust EPUB typography, and settle into focus mode.
- Listen with browser read-aloud where text and voices are available.
- Keep your reading progress and preferences synced across devices.

## Built with

React, TypeScript, Vite, and Tailwind CSS, with Supabase for accounts, data, and file storage. PDF.js and EPUB.js power the readers, while the Web Speech API provides read-aloud.
